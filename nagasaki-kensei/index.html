長崎県政に求めるもの

559件

県民意見は、税・予算の透明化と無駄削減で財源を確保し、離島医療や通院支援、通年ドクターヘリ、県内雇用・人材育成へ優先配分することを求めています。石木ダムなど大型事業は独立検証と代替案比較を義務付け、利権排除と説明責任を強化することが強く示されました。移動利便性・防災力向上では西九州新幹線の早期全線化や幹線道路・離島航路・空港連携、老朽インフラ改修が重視され、若者定着には賃上げ・家賃補助・保育無償化・教育・職業訓練などの包括策が挙げられています。全体としてDX・行政スリム化・市民参加・透明性向上を通じ、生活密着施策と環境保全の両立を図ることが求められています。

知事主導で迅速に企業誘致・中小・一次産業へ投資し、賃上げ・家賃補助と福祉強化で若者定着と地域経済を活性化する施策

134件

行政経験あるリーダーによる迅速な実行と成果の可視化を前提に、長崎の国際性を活かした企業誘致と中小企業・一次産業への資金投下・ブランド化・販路拡大を進め、雇用創出と事業の安定収益を図ります。同時に賃上げ・家賃補助・子育て支援で若年層の生活基盤を支え、奨学金返済と就労を両立できる処遇改善を行います。障害者福祉は通所施設の開所時間延長や障害年金の受給しやすさ向上など運用面を改善し、貧困や就労障壁の解消を図ります。県北の観光振興や南有馬漁港など現地確認・支援を通じた地域間格差是正、教育・人材育成による地元定着促進も併せて実施し、具体的なKPIと情報発信で成果を検証・公表します。

高校進路欄で地元就職・在宅勤務を明示し、県職員の定住モデル提示と人事改革・地代引下げで若年流出を抑制する総合施策

このレポートはgoogleフォームで収集したパブリックコメントを基に作成されています 分析対象となったデータの件数は288件で、これらのデータに対してOpenAI API (gpt-5-mini)を用いて559件の意見（議論）を抽出し、クラスタリングを行った。

分析手順

抽出 (gpt-5-mini)
コメントデータから意見を抽出するステップです。
埋め込み (text-embedding-3-small)
抽出された意見に対して埋め込み（ベクトル表現）を生成するステップです。
これにより、意見の内容を数値ベクトルとして表現します。
意見グループ化
埋め込みベクトルの値に基づいて意見の意見グループ化を行うステップです。
初期ラベリング (gpt-5-mini)
意見グループ化の結果に対して、各意見グループに適切なタイトル・説明文を生成（ラベリング）するステップです。
このステップでは、最も細かい粒度の意見グループ（最下層の意見グループ）に対して、各意見グループに属する意見に基づいて意見グループのタイトルと説明文を生成します。
統合ラベリング (gpt-5-mini)
意見グループを統合し、統合されたグループのタイトルと説明文を生成（ラベリング）するステップです。
このステップでは、下層の意見グループのタイトル及び説明文と、意見に基づいて上層の意見グループのタイトル及び説明文を生成します。
要約 (gpt-5-mini)
意見グループの概要を作成するステップです。
各意見グループのタイトル及び説明文をもとに、全体の概要をまとめます。
出力
最終的な結果を出力するステップです。
意見および各分析結果を含むJSONファイルを出力します。
表示
出力されたJSONファイルをグラフィカルに表示するステップです。
意見グループの概要、意見の内容などを可視化します。あなたが見ているこの画面が出来上がります。
